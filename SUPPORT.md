# Support

Choose the smallest public channel that fits the question:

- [**Discussions / Q&A**](https://github.com/JetXu-LLM/LlamaPReview/discussions/categories/q-a)
  for setup, configuration, and self-hosting questions.
- [**Discussions / Ideas**](https://github.com/JetXu-LLM/LlamaPReview/discussions/categories/ideas)
  for open-ended product proposals.
- [**Bug report**](https://github.com/JetXu-LLM/LlamaPReview/issues/new?template=bug_report.yml)
  for a reproducible defect in a supported release.
- [**Review-quality report**](https://github.com/JetXu-LLM/LlamaPReview/issues/new?template=review_quality.yml)
  for a missed issue, false positive, severity,
  inline-placement, Markdown, or Mermaid problem using only public or redacted
  evidence.
- [**Private vulnerability report**](https://github.com/JetXu-LLM/LlamaPReview/security/advisories/new)
  for security issues; see [SECURITY.md](SECURITY.md).

The official hosted service is for public repositories. Do not post private
source, secrets, raw provider payloads, installation IDs, or private logs in any
public channel.

Support is maintained by the project community and does not carry a guaranteed
response time. Clear reproductions tied to an exact release or commit are the
fastest route to a useful answer.
